# ⚡ UMM Analyzer Pro

**Industrial Monitoring & Data Analysis Platform for VSD Specialists**

---

## 📊 Descripción

UMM Analyzer Pro es una aplicación profesional para el análisis de datos de variadores de frecuencia (VSD). Permite cargar archivos `.umm`, extraer datos binarios, aplicar escalado automático y visualizar parámetros en tiempo real.

---

## 🎯 Características

- 📂 **Carga de archivos** `.umm` (arrastrar y soltar)
- 🔍 **Extracción automática** de datos binarios
- 📊 **Escalado automático** de parámetros (Hz, A, V, RPM, kW, Nm)
- 📈 **Visualización interactiva** con gráficos Plotly
- 📋 **Análisis estadístico** completo
- 📥 **Exportación** a CSV, Excel, JSON, ZIP y HTML
- 🎨 **Interfaz profesional** con diseño moderno

---

## 🛠️ Tecnologías

- **Frontend:** Streamlit
- **Visualización:** Plotly
- **Procesamiento:** Pandas, NumPy
- **Despliegue:** Vercel

---

## 🚀 Cómo usar

1. **Sube tu archivo** `.umm` desde el panel lateral
2. **Procesa** el archivo con un solo clic
3. **Explora** los datos en el dashboard interactivo
4. **Exporta** los resultados en múltiples formatos
